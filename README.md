# Vitrola

**▶ Abrir o Vitrola: [cicer0liveira27-star.github.io/vitrola](https://cicer0liveira27-star.github.io/vitrola/)**

Player de música que toca os arquivos de áudio do próprio aparelho, com pastas por artista, categorias por gênero, capas, playlists e fila.

As músicas que cada pessoa adiciona ficam guardadas só no navegador dela e nunca vão para este repositório.

O Vitrola não vem com músicas: cada pessoa adiciona as suas, uma a uma, a partir do próprio aparelho.
